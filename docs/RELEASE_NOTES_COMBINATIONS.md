# 共同路段组合展示（待发布）

状态：2026-10-26 源码开发版本，待版本化发布。用户已授权推送功能分支，
GitHub CI 通过后合并到 `main`；本轮不创建新 Release 或版本标签。

## 本轮新增

- 默认组合视图，呈现共同前段、同向备选公交和后续共同走廊。
- 分支选择保留原始路线关联，防止无依据的路径拼接。
- 区分同车继续和换乘；每条完整路线保留原估时、等待、缓冲与换乘次数。
- 可切回独立路线，展开站序、分页查看候选、选择原路线并使用途中参考。
- 只读本机组合接口，复用查询身份、过期、Host / Origin / CSRF 检查。
- README 精简并加入项目截图，旧任务板归档，历史比较补齐生成步骤。

同批源码整合还包含此前完成的自选站点和独立碎片实验，按独立实验、
基础模块、界面集成和文档分组审阅提交；这些工作不等于已发布新版本。
